We are doing a minimal implementation of ping in C programming.
You have the subject here named ft_ping.pdf, it contain all the instructions to follow, we don't do any bonus, only the mandatory part.
We are taking as reference the implementation of ping from inetutils-2.0 .
There is a VM running ping from inetutils-2.0 that you can access through ssh at bully@192.168.122.175 to be able to test ping of inetutils-2.0 .
The Folder Documentation contains some reference data : the output of the man of ping from inetutils-2.0 and the real code of ping from inetutils-2.0, don't forget that we do a minimal implementation of it we don't want to implement all the complex details of this code.

Our project structure is simple : we have the header file at includes/ft_ping.h , and all the C files into srcs folder.
